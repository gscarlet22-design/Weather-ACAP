Threshold → port mapping

Fire a port when a numeric condition crosses a value — heat, freeze, high wind, humidity. There is no hysteresis, so pick values with margin: a reading hovering on the threshold toggles the port every poll.

⚡ Lightning & thunderstorm risk

Checks the NOAA Storm Prediction Center Day-1 Convective Outlook and activates a port when your coordinates fall inside a risk polygon. Free public GeoJSON, no API key.

SPC updates roughly hourly. At 5-minute polling, 6 cycles is every 30 min.

    MQTT publishing

    Publish JSON weather and alert payloads to any MQTT broker. Requires libcurl built with MQTT support (AXIS OS 12+).

    Scheme, host and port only — no trailing slash.
    —

    Email notifications

    Sends an email when an alert activates, and optionally when it clears. With a username set, STARTTLS is required so credentials never travel in the clear; without one it is attempted opportunistically. Server certificates are not verified, so self-signed internal relays work.

    smtp:// for plain/STARTTLS, smtps:// for implicit TLS.
    Separate multiple recipients with commas.
    —

    Native AXIS events

    Publishes alerts and conditions as native camera events via axevent. They appear in Action Rules under Applications → Weather Monitor ACAP and are visible to Axis Camera Station Pro and ONVIF subscribers. Virtual input ports are unaffected.

    Alert fires on every NWS / threshold transition — active, alert_type, action. Conditions fires on every successful poll — temp_f, wind_mph, humidity_pct, description.

    Mock mode

    Skips the real weather fetch and uses a fixed snapshot with a Tornado Warning active — good for bench-testing VMS integrations. A sticky banner shows while it is on.

    Structured JSON logging

    Also writes JSON log lines to stderr alongside syslog: {"ts":"…","level":"info","app":"weather_acap","msg":"…"} — for Loki, Splunk, Datadog or any aggregator reading the device syslog stream.

    Backup & restore

    Export from one device and import into another to deploy identical settings across a fleet.
