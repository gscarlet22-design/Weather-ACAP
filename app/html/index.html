Alert history

    System

    Master switch. Turn off to pause the poll loop without uninstalling.

    VAPIX credentials

    Used for localhost VAPIX Digest auth (virtual ports + overlay). Required when your device is configured with authentication.

    Webhook on alerts

    POST a payload to any URL when an alert activates or clears. Supports custom templates for Slack, Discord, Teams, and Home Assistant.
    Presets:
    When blank, the default JSON body is sent. Set a template to customise for your service.

    MQTT publishing

    Publish JSON weather and alert payloads to an MQTT broker. Requires libcurl built with MQTT support (available on AXIS OS 12+).
    Scheme + host + port only — no trailing slash.
    —

    Email notifications

    Send an email when an alert activates (and optionally clears). Uses your SMTP relay. With a username set, STARTTLS is required so credentials never travel in the clear; without one it is attempted opportunistically. Server certificates are not verified (self-signed internal relays work).
    Use smtp:// for plain/STARTTLS or smtps:// for implicit TLS.
    Separate multiple recipients with commas.
    —

    Native AXIS Events

    Publish weather alerts and current conditions as native camera events via the AXIS event system (axevent). Events appear in Action Rules under Applications → Weather Monitor ACAP and are visible to Axis Camera Station Pro and ONVIF subscribers. Virtual input port activation is unaffected.

    Alert event fires on every NWS / threshold transition (stateful) — active, alert_type, action.
    Conditions event fires on every successful poll (stateless) — temp_f, wind_mph, humidity_pct, description.

    Mock mode

    Skip real weather fetch and use a fake snapshot with a Tornado Warning active. Good for bench-testing VMS integrations.

    Structured JSON Logging

    When enabled, the daemon also writes structured JSON log lines to stderr alongside standard syslog entries. Each line is a JSON object: {"ts":"…","level":"info","app":"weather_acap","msg":"…"}
    Useful for ingestion by Loki, Splunk, Datadog, or any JSON log aggregator that reads the device syslog stream.
